# vNext「解题手账」视觉改版

## 目标

把画布中确认的设计稿落到 `src/vnext`：平台首页、比赛题目工作区与积分榜改为纸面底色、墨色控件、衬线标题和手绘拼贴插图，整套壳层同步换成顶部胶囊导航。任务在独立工作目录 `../webserver-vnext-redesign` 的 `codex/vnext-redesign` 分支进行，未改动主目录中 `codex/local-demo` 的未提交工作。

## 决定

- 语义 Token 保留原名，只替换取值；新增 `--yn-color-signal`、`--yn-color-ink`、`--yn-color-hatch`、`--yn-color-dim`、`--yn-font-serif`、`--yn-font-display`、`--yn-font-hand` 与 `--yn-art-*` 印刷色。其他页面随 Token 一起换色，布局不变。
- `[data-yn-band]` 是反相色带：日间主题下为深色，夜间主题下为浅色。积分榜「解题时间轴」使用它。
- 壳层去掉左侧模块栏，改为固定顶栏：左侧主要模块胶囊与「全部」抽屉入口，中间平台字标，右侧主题切换与个人中心。新增跳到主要内容的链接与深色页脚。`--yn-context-height` 桌面 72px、窄屏 112px，依赖它的吸顶元素无需改动。
- 比赛工作区拆为不吸顶的赛事标题区与吸顶的分区栏（`--yn-game-bar-height` 64px，窄屏 104px），保持 AWDP、组网、理论工作台的吸顶偏移。
- 插图全部是内联 SVG 组件，位于 `features/home/HomeHeroArt.tsx`、`HomeCardArt.tsx`、`games/challenges/ChallengeArt.tsx` 与 `games/scoreboard/ScoreboardArt.tsx`。插图中的可见文字只用英文，图案 id 由 `useArtId` 生成以免重复。装饰插图不含业务数据；积分榜插图中的名次、分数、一血数与分差全部来自当前积分榜。
- vNext 禁止内联 style，动态长度一律用 SVG 属性（积分条）或 CSS 网格与 `data-*` 状态（时间轴、矩阵、章节方块）。
- 一血名次优先取题目 `bloods` 顺序，缺失时回退到提交类型；演示后端的提交类型都是 `Normal`，仅靠类型会丢失一血。
- 首页副标题沿用 `PLATFORM_TYPE`（安全综合演练平台），与现有品牌常量保持一致。
- 字体通过 `vite-plugin-webfont-dl` 在构建期下载：Newsreader、Noto Serif SC（400，按 unicode-range 分片）、Archivo 宽体、Caveat。CSP 无需修改。

  - 赛制写比赛类型（CTF、AWDP、混合赛制等），后面附「个人赛 / 团队赛」。
  - 参赛人数即原来的小人图标 +「每队最多 N 人」。
  - 标题上方的赛制标签与赛制格重复，已去掉，只留比赛状态。
- 去掉标题下的比赛简介：它与说明正文第一句重复。比赛没有填写说明时，说明区仍回退显示简介。
- 赛事说明：说明正文若以一级或二级标题开头（演示数据为「## 赛事说明」），显示时去掉这行标题，数据不变（`withoutLeadingHeading`，有测试）。
- 比赛公告：悬浮的公告卡片里，每条公告是一张带边框、页面底色的小卡片（卡片套卡片），展开动画与关闭方式不变。

- 事实栏再合并：赛制与每队人数合为「赛制」一格，先写比赛类型，下一行用小号字写小人图标与「每队最多 N 人」（个人赛时为「个人参赛」）。「已报名」的数字不再放大，与其他格同一字号。现为「赛制 · 已报名 · 赛区」三格，外加只在设置了时出现的规则格。
- 「赛制」格不再写比赛类型（如「混合赛制」），只留小人图标与「每队最多 N 人」，字号与其他格一致；不再使用的赛制名称函数已删除。
